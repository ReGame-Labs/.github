# ReGame Labs

**Matching decompilations of Games classics.**

We take games we love and turn them back into readable C source, source that
compiles with the original tools into the very same game, byte for byte.

This organization hosts only that: decompilation projects. Nothing else lives here.

## Good to know

- **No game data.** The repositories hold code and tools only. To build a game
  you need your own copy of it.
- **Matching, not "close enough".** Every build is checked against the original
  executable, with the compilers the game was made with.
- **Open progress.** Each release's progress is public on [decomp.dev](https://decomp.dev)
- **Tracking.** Check the project tracking here [recomp.fyi](https://recomp.fyi/)
